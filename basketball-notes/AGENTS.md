# 籃球練習筆記：AI 開發指引

## 專案目的與範圍
製作簡單、容易閱讀的籃球練習筆記網站，讓初學者閱讀三分球與運球筆記，並計算單次投籃命中率。使用繁體中文及短句。這是靜態網站，不需要 API、登入、資料庫或套件安裝。

## 檔案結構
- index.html：首頁、專案動機與筆記入口。
- notes/three-point.html：三分球練習筆記。
- notes/dribbling.html：運球練習筆記。
- notes/shooting-rate.html：命中率筆記與計算器。
- assets/style.css：全站共用樣式。新增頁面優先沿用，不另寫整套樣式。
- assets/app.js：命中率計算與表單互動。
- templates/note.html：新增筆記的起始版型，不放入首頁導覽。
- checks.mjs：檢查連結、筆記格式與計算器的開發工具，不由網頁載入。
- AGENTS.md：本指引，適用本資料夾及子資料夾。
- YYYYMMDD_繳交說明.md：作業介紹與連結。

## 網頁風格
白底、深色文字、橘色重點。使用系統字體，不依賴外部字體、圖片或 CDN。寬度最多 1120px，手機改為單欄；按鈕與連結必須可用鍵盤操作。正文使用易讀字級，保留清楚的 focus 樣式。裝飾圖形以 CSS 或內嵌 SVG 製作。

## 固定頁面結構
首頁包含網站名稱、簡介、三篇筆記入口及頁尾。每篇筆記依序包含：
1. 返回首頁連結、分類編號、標題與一句摘要。
2. 「練習目標」。
3. 「練習方法」：使用有順序的步驟，保持簡單。
4. 「注意事項」。
5. 「練習紀錄」：提出可記錄的資料；只有命中率頁需要互動表單。
6. 上一篇／下一篇導覽，連結需對應實際存在的頁面。

## 新增一篇筆記的流程
1. 先讀本指引，確認新主題沒有重複。
2. 複製 templates/note.html 到 notes/，檔名使用小寫英文加連字號，例如 passing.html。
3. 替換所有 {{...}} 佔位字，保留上述四個內容區塊與共用樣式。
4. 子頁引用 ../assets/style.css；返回首頁用 ../index.html。所有站內網址使用相對路徑，確保 GitHub Pages 子目錄及本機開啟都可使用。
5. 首頁新增一張相同 .note-card 卡片，更新筆記數量及相鄰文章導覽。不要自行改掉整站設計。
6. 執行 node checks.mjs，並在瀏覽器點開新增頁面及返回首頁，檢查手機寬度與鍵盤操作。
7. 若變更規則或結構，同步更新本指引及繳交說明。

## 內容規則
每篇約 200–400 個中文字。以初學者、單人練習為主。不要虛構名人語錄、命中率、比賽數據或保證進步。Curry 只出現在個人動機，不宣稱代言或使用其照片。避免硬性規定人人適用的投籃距離、關節角度；強調選擇可控制的距離。不根據單次命中率診斷姿勢或身體狀況。不要在網站填入姓名、學號等繳交識別資料。

## 計算器規則
輸入必須是非空白、有限且安全的整數。出手次數大於零，命中次數介於零與出手次數之間。計算式為 命中 ÷ 出手 × 100%，顯示到小數一位。錯誤輸入以繁體中文說明，清除過期結果；輸入變更時也清除舊結果。按重設恢復空白狀態。結果使用 aria-live 提示。不使用 eval、外部 API 或模型產生計算結果。

## 完成前確認
- node checks.mjs 通過：連結、固定章節、20投8中＝40.0%、零命中、全命中、空白、零出手、負數、小數與命中超過出手等情形。
- 實際檢查桌面與手機、Tab焦點及計算／重設。
- 沒有佔位字、損壞連結、密鑰或個資。
